# 真人成片记录（cases）

> 状态：还没有记录。作者规则要升级成"有把握"的规则，靠这里的记录；单次观察不写成规则，失败也要记。

## 一条记录写什么
文件名：`YYYY-MM-DD-简称.md`。内容：
- 日期、平台（豆包／LibTV）、模型版本（2.0／2.5）、时长与画幅。
- 提示词全文（复制区原样）与参考图清单（每张提供什么、不采用什么）。
- JIN 的评价（用他的原话，不改写）。
- 命中的规则（R 编号）；哪些做到了，哪些没做。
- 支持还是反驳哪条规则；是不是单变量对照（只改了一件事？）。
- 备注：成片里具体哪里对、哪里错（写秒数）。

## 升级规则
- 一条记录最多让一条规则从"作者原则"变成"单次验证"，要写明验证的是哪条规则的哪个说法。
- 同类规则在不同任务重复成立，才可以在入口标注为"已验证"。
- 反驳的记录同样写进对应主题卡的"注意"里。
- 已通过的提示词与成片是冻结基线，不擅自重写。
